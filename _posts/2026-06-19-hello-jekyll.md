Интернэтэд өөрийн блог, хувийн вэбсайт эсвэл бизнесийн танилцуулга сайттай болохыг хүсдэг ч хостинг болон домэйнд сар болгон мөнгө төлмөөргүй байна уу?

Сайн мэдээ — та **[GitHub Pages](https://pages.github.com/)** ашиглан бүрэн **үнэгүй** вэбсайт ажиллуулах боломжтой. Хэрэв та программист биш байсан ч энэхүү аргыг ашиглан өөрийн блог, портфолио эсвэл жижиг бизнесийн вэбсайтыг хэдхэн минутын дотор үүсгэж болно.

> 💡 **Жишээ:** Энэ блог өөрөө [GitHub Pages + Jekyll](https://pythonisaur.github.io/myjekyll/) дээр ажилладаг — сарын зардал **0₮**.

---

## GitHub Pages гэж юу вэ?

[GitHub Pages](https://pages.github.com/) нь [GitHub](https://github.com)-аас санал болгодог **үнэгүй вэб хостинг үйлчилгээ** юм. Та өөрийн вэбсайтын файлуудаа GitHub-д байршуулснаар автоматаар интернетэд нийтлэгдэнэ.

Жишээ нь:

- Хувийн блог
- Портфолио сайт
- CV / Resume
- Бизнесийн танилцуулга
- Сургалтын вэбсайт
- Баримт бичгийн сайт (Documentation)

зэрэг олон төрлийн сайтыг үнэгүй ажиллуулж болно.

---

## Яагаад GitHub Pages ашиглах хэрэгтэй вэ?

### 1. Үнэгүй 🆓

Сарын төлбөр байхгүй:

- Хостинг: **0₮**
- SSL сертификат: **0₮**
- Серверийн зардал: **0₮**

### 2. Хурдан ⚡

GitHub Pages нь статик сайт ажиллуулдаг тул маш хурдан ачаалдаг.

### 3. Найдвартай 🔒

GitHub бол дэлхийн хамгийн том хөгжүүлэгчдийн платформуудын нэг. Таны сайт өндөр найдвартай орчинд ажиллана.

### 4. Өөрийн домэйн холбох боломжтой 🌐

Хэрэв хүсвэл:

- `myblog.com`
- `bat.mn`
- `mybusiness.com`

зэрэг өөрийн домэйнийг холбож болно.

---

## Jekyll гэж юу вэ?

GitHub Pages нь **[Jekyll](https://jekyllrb.com/)** нэртэй системийг дэмждэг. Jekyll нь **Markdown** хэлбэрээр бичсэн нийтлэлүүдийг автоматаар гоё вэб хуудас болгон хөрвүүлдэг.

Дэлхийн хамгийн алдартай статик сайт бүтээгчдийн нэг бөгөөд [GitHub Pages-тэй бүрэн нэгдсэн](https://docs.github.com/en/pages/setting-up-a-github-pages-site-with-jekyll) ажилладаг.

Жишээ нь:

```markdown
# Миний анхны нийтлэл

Сайн байна уу?
```

гэсэн текст автоматаар мэргэжлийн харагдах блог нийтлэл болж хувирна.

---

## Блог нийтлэл бичих ямар давуу талтай вэ?

Хэрэв та:

- Мэргэжлээ сурталчлах
- Ажлын туршлагаа хуваалцах
- Англи хэл сурах
- Программчлал заах
- Аяллын тэмдэглэл бичих
- Хувийн брэндээ хөгжүүлэх

гэж байгаа бол блог маш хүчтэй хэрэгсэл болдог.

> Өнөөдөр олон ажил олгогчид CV-ээс илүү таны бүтээсэн контентыг хардаг болсон.

## Хэрхэн эхлэх вэ?

### Алхам 1 — GitHub аккаунт үүсгэх
[github.com](https://github.com) руу орж үнэгүй бүртгэл үүсгэнэ. Бүртгэл нь 2 минут л орно.

### Алхам 2 — Шинэ repository үүсгэх
`New repository` товч дарж шинэ repo үүсгэнэ. `username.github.io` гэсэн нэр өгвөл автоматаар GitHub Pages идэвхжинэ.

### Алхам 3 — Jekyll template сонгох
[Jekyll Themes](https://jekyllthemes.io/) эсвэл [GitHub Pages Themes](https://pages.github.com/themes/) хуудаснаас үнэгүй загвар сонгоно.

### Алхам 4 — Нийтлэлээ Markdown ашиглан бичих
[Markdown](https://www.markdownguide.org/) маш энгийн хэл. Тэмдэглэлийн дэвтэрт бичдэгтэй адил бичвэл болно.

### Алхам 5 — GitHub руу push хийх
Файлуудаа GitHub руу байршуулахад сайт автоматаар нийтлэгдэнэ. 1-2 минутын дотор амьд болно!
