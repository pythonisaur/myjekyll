Миний [X данс](https://x.com/coderjs1) дээрх хөдөлгөөнт пост бүр яг нэг аргаар бүтдэг: би Claude-д санаагаа хэлээд, хэдхэн минутын дараа нийтлэхэд бэлэн, төгс давтагддаг GIF гарч ирдэг. After Effects ч үгүй, Canva-гийн төлбөрт эрх ч үгүй, AI видео кредит ч үгүй. Бүх дамжлага нь ердөө нэг markdown файл, нэг HTML загвар, нэг Python скрипт.

Эцсийн бүтээгдэхүүн нь ямар харагддагийг эхлээд үзүүлье:

![TestLogicHub — хөдөлгөөнт GIF карт](/myjekyll/assets/blog/claude-social-gif/testlogichub.gif)

Энэ бол 800×800 хэмжээтэй, 6 секунд тутамд саадгүй давтагддаг GIF. Энгийн HTML файлаас рендэрлэгдсэн. Энэ нийтлэлд дамжлага хэрхэн ажилладаг, яагаад HTML + CSS нь миний туршсан бүх хэрэгслээс илүү болохыг тайлбарлана.

## Дамжлагын ерөнхий зураг

<pre class="mermaid">
flowchart LR
    A["💡 Санаа<br/>баримт бичиг, шинэ фичер,<br/>хурц бодол"] --> B["📝 brief.md<br/>Claude шүүж авна:<br/>гарчиг, жагсаалт, CTA"]
    B --> C["🎨 card.html<br/>загвар + токен<br/>цэвэр CSS хөдөлгөөн"]
    C --> D["🎞️ render_gif.py<br/>Playwright цагийг<br/>кадр кадраар гүйлгэнэ"]
    D --> E["✅ final.gif<br/>саадгүй 6с давталт<br/>X-д &lt; 15 MB"]
    E --> F["🚀 Нийтлэх<br/>X / LinkedIn<br/>тайлбартай нь"]
</pre>

Гурван файл формат, гурван хувиргалт. Claude ([Claude Code](https://claude.com/claude-code) дотор агент болж ажиллана) энэ бүгдийг асуулт асуулгүйгээр хийдэг — учир нь оператор хүний шийдэх ёстой байсан шийдвэр бүр аль хэдийн config файл эсвэл загварт бичигдсэн байдаг.

## 1-р алхам — Санаа → brief.md

Brief бол "юу хэлэхийг хүссэн" болон "юу рендэрлэгдэх" хоёрын хоорондох гэрээ. Claude миний заасан зүйлийг — release notes, репо, дутуу боловсорсон бодол — уншаад, нэг дэлгэцэд багтах мессеж болгон шүүнэ.

Энэ нийтлэлийн эхэнд байгаа GIF-ийг бүтээсэн жинхэнэ brief нь энэ:

```markdown
---
slug: testlogichub
kicker: TESTLOGICHUB
title: Pass your **Databricks** cert on the first try.
subtitle: Official-style practice exams — timed, weighted, and explained like the real thing.
cta: testlogichub.com
brand: TESTLOGICHUB
---
- [check] Every question comes with a full **explanation**
- [chart] Section weights match the **official exam**
- [shield] Data Engineer · ML · GenAI · Analyst tracks
- [loop] Timed runs, score history, retake anytime
```

Дүрэм нь зориудаар хатуу: гарчиг ≤ 8 үг, ≤ 4 жагсаалт, нэг пост — нэг санаа. `**bold**` нь гарчигт гялалзсан шар өнгө болно. `[loop]`, `[check]` гэх мэт угтварууд дүрс тэмдэг болж хувирна. Хэрэв санаа чинь энэ хязгаарт багтахгүй бол хангалттай шүүгдээгүй гэсэн үг — формат нь өөрөө тодорхой байдлыг шаарддаг хэрэгсэл юм.

## 2-р алхам — brief.md → хөдөлгөөнт HTML

Парсер токен бүхий загварыг ({% raw %}`{{TITLE}}`, `{{BULLETS}}`, `{{CTA}}`{% endraw %}…) бөглөж `card.html` файлыг үүсгэнэ: аврора дэвсгэр, дүрс тэмдэгтэй жагсаалт, гялалзсан гарчиг, тойрог замд эргэх гэрэлтэй цэг, булан дахь дугуй брэнд аватар. Бүх хөдөлгөөн **цэвэр CSS** — зөвхөн keyframes, JavaScript таймер огт үгүй.

Яагаад видео хэрэгслийн оронд HTML, CSS гэж?

- **Үнэгүй.** Рендэр ферм ч үгүй, кредит ч үгүй, төлбөрт эрх ч үгүй. Хөтөч өөрөө рендэрлэгч нь.
- **Diff хийж болно.** "Дизайн файл" нь текст. Claude түүнийг код шиг засаж, хянаж, хувилбаржуулж чадна.
- **Брэндтэй.** Өнгө, фонт, аватар байрлал бүгд нэг загварт байдаг. Пост бүр нэг данснаас гарсан мэт харагддаг — учир нь үнэхээр тийм.
- **Детерминистик** — энэ бол бүх аргын гол нууц бөгөөд дараагийн алхамд тайлбарлана.

## 3-р алхам — HTML → GIF: хамгийн ухаалаг хэсэг

Хөтчийн дэлгэцийг шууд бичлэг хийж болохгүй: цаг хугацаа чичирнэ, кадрууд тасарна, давталт хэзээ ч эхэлсэн цэгтээ яг буцаж очихгүй. Рендэрлэгч тэс өөр арга хэрэглэдэг — **цагийг зогсоогоод, гараар гүйлгэдэг**:

<pre class="mermaid">
sequenceDiagram
    participant P as render_gif.py
    participant B as Chromium (Playwright)
    participant G as Pillow
    P->>B: card.html-ийг ачаална
    P->>B: бүх CSS хөдөлгөөнийг зогсооно
    loop 90 кадр (15 fps × 6 с)
        P->>B: animation-delay = -t (цагийг t кадр руу гүйлгэнэ)
        B-->>P: t кадрын дэлгэцийн зураг
    end
    P->>G: 90 PNG-г нэгтгэнэ
    G-->>P: final.gif (төгс давталт, огт зөрөхгүй)
</pre>

Цагийг ажиглахын оронд гараар гүйлгэдэг учраас кадр бүр пиксел хүртлээ детерминистик — нэг HTML-ийг хоёр удаа рендэрлэвэл байт бүр нь ижил GIF гарна.

Саадгүй давталтын нууц нь ердөө нэг арифметик дүрэм: **CSS хөдөлгөөн бүрийн үргэлжлэх хугацаа нийт хугацааг бүхлээр хуваах ёстой**. 6 секундэд энэ нь 1.5 с, 2 с, 3 с, эсвэл 6 с гэсэн үг. 90 дэх кадр 0 дэх кадртай яг ижил тул давталтад "оёдол" харагдахгүй — нүд хэзээ ч дахин эхэлснийг олж харахгүй.

```css
/* ✅ 6с GIF-д саадгүй давтагдана */
.orbit   { animation: spin 3s linear infinite; }
.shimmer { animation: sweep 2s ease-in-out infinite; }

/* ❌ 2.5с нь 6-г бүхлээр хуваахгүй — давталтын цэг дээр үсрэлт харагдана */
.bad     { animation: pulse 2.5s ease infinite; }
```

## Санаа бүр GIF карт байх албагүй

Карт загвар бол гол ажлын морь, гэхдээ формат нь санаагаа дагах ёстой. Нэг дамжлага өөр өөр рендэрлэгч рүү чиглүүлдэг:

| Санаа чинь юу вэ… | Формат | Хэрэгсэл |
|---|---|---|
| ойлголт + богино жагсаалт | Хөдөлгөөнт GIF карт | дээрх загвар |
| өргөн хүрээний, ойр дотно сэдэв | "Сэтгүүлийн нүүр" загвар | хоёр дахь загвар, serif гарчиг |
| ямар нэг зүйл хэрхэн ажилладаг/эвдэрдэг | Диаграм | mermaid/HTML → PNG |
| харьцуулалт эсвэл тоо | График | HTML график → PNG |
| тусгай хөдөлгөөнт зураглал | Өөрийн CSS сцен | гараар бичсэн HTML → мөн л GIF рендэрлэгч |

"Сэтгүүлийн нүүр" загвар нь аврора картын оронд цайвар өнгийн сэтгүүлийн нүүр ашигладаг — brief-ийн формат нь яг ижил, харагдах байдал нь тэс өөр:

## Агент яг юу хийдэг вэ?

Энд Claude зохиолч байхаа больж, оператор болдог. "X сэдвээр пост хий" гэхэд агент бүх гинжин хэлхээг өөрөө гүйцэтгэнэ:

<pre class="mermaid">
flowchart TD
    A["Эх материалыг уншина"] --> B["brief.md +<br/>caption.txt бичнэ"]
    B --> C["python tools/make_post.py --slug the-slug"]
    C --> D["Давталтын дундах кадрыг<br/>гаргаж аваад нүдээрээ шалгана"]
    D --> E{"Текст багтсан уу? Тод харагдаж байна уу?<br/>Файл &lt; 15 MB уу?"}
    E -- үгүй --> B
    E -- тийм --> F["GIF + тайлбарыг хүлээлгэж өгнө"]
    F --> G["Хүн зөвшөөрнө → пост нийтлэгдэнэ"]
</pre>

Харагдахаасаа илүү чухал хоёр нарийн зүйл:

1. **Агент нүдээр шалгадаг.** Бэлэн GIF-ээс нэг кадр гаргаж аваад өөрөө хардаг — халисан текст, муу контраст надад ирэхээс өмнө баригддаг. "Алдаагүй рендэрлэгдлээ" гэдэг нь "зөв харагдаж байна" гэсэн үг биш.
2. **Нийтлэх эрх хүнд үлддэг.** Агент постыг бэлдэнэ; товчийг хүн дардаг. Автоматжуулалт үйлдвэрлэлийг хариуцна, харин эцсийн шийдвэрийг биш.

## Дүгнэлт

- **Текст орж, пиксел гарна.** Markdown brief → HTML загвар → GIF. Бүх завсрын бүтээгдэхүүн хувилбаржих боломжтой, дизайн систем нь ганц загвар файлд байдаг.
- **Детерминизм нь бичлэгээс илүү.** CSS хөдөлгөөнийг зогсоогоод цагийг гараар гүйлгэ — пиксел төгс кадрууд, оёдолгүй давталт.
- **Давталтын арифметик энгийн ч заавал биелэх ёстой:** хөдөлгөөн бүрийн хугацаа GIF-ийн нийт хугацааг бүхлээр хуваах ёстой.
- **Хязгаарлалт бол чанарын шалгуур.** Гарчиг ≤ 8 үг, ≤ 4 жагсаалт гэдэг дүрэм ямар ч фильтрээс илүү үр дүн өгдөг.
- **Нэмэлт постын өртөг тэг.** Үнэтэй хэсэг нь — мэдрэмж, загвар, дамжлага — ганц л удаа төлөгддөг.

Ашигласан стек: агент нь [Claude Code](https://claude.com/claude-code), рендэрлэгч нь Playwright + Chromium, GIF угсрагч нь Pillow, энэ бүгдийг холбосон 300 орчим мөр Python. HTML бичиж чаддаг л бол та аль хэдийн өөрийн гэсэн motion-graphics студитэй болсон гэсэн үг.
